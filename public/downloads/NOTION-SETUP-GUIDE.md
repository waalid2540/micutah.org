# Ramadan Planner 2026 - Notion Template Setup

## Quick Start

1. Go to notion.so and create a new page
2. Name it "🌙 Ramadan Planner 2026"
3. Copy/paste sections below OR import the CSV files for databases

---

## Option A: Quick Import (Recommended)

Import these CSV files as databases:
- `daily-tracker.csv` → Your 30-day tracker
- `duas.csv` → All 30 duas with translations
- `quran-tracker.csv` → Juz-by-juz tracker

---

## Option B: Manual Setup

## Pre-Ramadan Checklist (Toggle List)

Copy this into a toggle block:

### Spiritual Preparation
- [ ] Make tawbah (repentance)
- [ ] Forgive everyone who wronged you
- [ ] Ask forgiveness from anyone you wronged
- [ ] Settle any debts
- [ ] List bad habits to break
- [ ] List good habits to build
- [ ] Set Quran goal
- [ ] Identify weak spots

### Practical Preparation
- [ ] Stock up on dates & healthy foods
- [ ] Meal plan for first week
- [ ] Clear schedule where possible
- [ ] Set up prayer space
- [ ] Download Quran app
- [ ] Find masjid Taraweeh schedule
- [ ] Calculate Zakat
- [ ] Prepare kids for Ramadan
